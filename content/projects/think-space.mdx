features:
  - name: One selection model
    detail: "Notes, text, four shapes, lines, arrows and pen strokes are rows in one `BoardItem` table, so a marquee catches mixed types and drags, resizes, restacks and undoes them as one group."

  - name: Optimistic sync
    detail: "Edits render locally and reconcile with the server's ack. A new item carries a `clientKey` across the id swap, so a note being typed into isn't remounted and half a sentence isn't lost."

  - name: Lossless resize
    detail: "Strokes store their points in `data.points` as fractions of their own bounding box, so scaling never rewrites geometry through the integer coordinate columns."

  - name: Roles enforced server-side
    detail: "Admin, editor, commenter and viewer are resolved on join, cached per socket, and re-checked on every message — a disabled button is not the security model."

  - name: Comments and reactions
    detail: "Threaded comments and emoji anchor to any item and render as badges on the canvas itself, not in a side panel you have to go looking for."

  - name: Export at 1:1
    detail: "The whole board, the current selection, or any rectangle you drag — always rendered at true scale, whatever zoom you happen to be at."

  - name: Keyboard-first tools
    detail: "Sticky notes that auto-fit their text, text boxes, four shapes, lines, arrows and a freehand pen, each one keystroke away: `N` `T` `S` `L` `A` `P`."

  - name: Eight templates
    detail: "Retro, roadmap, user journey, mind map, flowchart and more — built from the same item types you'd draw by hand, so a template can be pulled apart like anything else."

  - name: Accounts, invites, billing
    detail: "Email invites with tokenised accept links for people without an account, TOTP two-factor, activity feed, command palette, WebRTC voice rooms and Stripe-backed plans."
